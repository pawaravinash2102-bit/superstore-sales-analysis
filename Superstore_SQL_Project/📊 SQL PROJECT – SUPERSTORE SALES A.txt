🔹 5️⃣ CATEGORY-WISE SALES ANALYSIS
Query:
SELECT 
    category,
    ROUND(SUM(sales), 2) AS total_sales
FROM superstore
GROUP BY category
ORDER BY total_sales DESC;


🧠 Logic Explained:

SUM(sales) → category ka total sales

GROUP BY category → category-wise data split

ORDER BY DESC → top category first

📊 Result:

Category	Total Sales
Technology	Highest
Furniture	Medium
Office Supplies	Lowest

🎤 Interview Explanation:

I grouped sales by product category to understand which category generates the highest revenue and ranked them using ORDER BY.

🔹 6️⃣ REGION-WISE PROFIT ANALYSIS
Query:
SELECT 
    region,
    ROUND(SUM(profit), 2) AS total_profit
FROM superstore
GROUP BY region
ORDER BY total_profit DESC;


🧠 Logic:

Profit aggregation

Region-wise grouping

Best performing region identification

📊 Result:

Region	Profit
West	Highest
East	Second
South	Third
Central	Lowest

🎤 Interview Line:

This analysis helped identify West region as the most profitable market.

🔹 7️⃣ SALES TREND ANALYSIS (YEAR-WISE)
Query:
SELECT 
    YEAR(order_date) AS year,
    ROUND(SUM(sales), 2) AS yearly_sales
FROM superstore
GROUP BY year
ORDER BY year;


🧠 Logic:

Extract year from date

Trend analysis using aggregation

Growth pattern identification

🎤 Interview Line:

I performed time-based analysis to observe year-over-year sales growth.

🔹 8️⃣ IMPORTANT SQL RULE (INTERVIEW FAVORITE)

❗ Golden Rule:

“Whenever we use aggregate functions with non-aggregated columns, GROUP BY is mandatory.”

Example:

SELECT category, SUM(sales)
FROM superstore
GROUP BY category;
